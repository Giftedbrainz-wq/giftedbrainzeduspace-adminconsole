Admin Security

Environment managed

Administrator credentials are deliberately stored only in the Admin Portal server environment. They are never written to the shared student database, browser storage, frontend code or ZIP package.

Admin username—
Admin email—
Credential storageAdmin server environment
Shared authenticationAUTH_SECRET
To change the administrator username, password or email, update ADMIN_USERNAME, ADMIN_PASSWORD or ADMIN_EMAIL in the Admin hosting environment and redeploy the Admin function. This prevents credentials from being persisted in application data.
